Expected Shot Danger

A shot-quality model that captures not just location, but context — including pressure, defensive positioning, and shot dynamics — to better estimate true scoring danger.

Entropy-Adjusted xG

An extension of traditional expected goals that accounts for uncertainty and variability in shooting outcomes, rewarding shots that create higher defensive entropy.

Goalkeeper Value Model

A framework for isolating goalkeeper impact by comparing post-shot outcomes against expectation, separating shot-stopping skill from team defensive effects.

Set Piece Model

A possession- and delivery-aware model evaluating the quality and threat of set pieces, from initial structure through second-ball and rebound phases.
