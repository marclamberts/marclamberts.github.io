Creating an Actionable Goalkeeper Value Model

I am a very chaotic person by nature, and I need structure to make sure everything works right. This makes me thrive. But when the structure isn’t good enough, projects can stay on the shelf for a long time. One of these projects was the Goalkeeper Value Model (GVM). Not anymore. I finished it — and I’m very happy with it.

Introduction

Goalkeepers are underrepresented in data studies. When they are evaluated, it is often only in relation to attackers — how good is the goalkeeper at preventing goals? What was the difficulty of the shot faced? These are questions tied to scoring metrics.

But goalkeeping is much more than shot-stopping. Distribution, leaving the line, reflexes, ball handling, sweeping — these are all measurable aspects. With the right distinctions, we can build new metrics, scores, and models that properly evaluate goalkeeper performance.

Data Collection

The data used is Opta/StatsPerform event data from the 2024–2025 Serie A season, collected on August 18th, 2025.

Working with Opta data requires careful preparation. Qualifiers must be used to extract endX and endY coordinates. Events and qualifiers are crucial for mapping goalkeeper actions. Only goalkeepers with a minimum of 900 minutes are included to ensure data stability.

Aim

The aim is to show what on-ball event data can do for goalkeeper analysis and to build a model that quickly communicates goalkeeper performance across matches and seasons.

Theoretical Framework

The model creates five scores:

  • Shot-stopping
  • Leaving the line
  • Distribution
  • Ball handling
  • Set piece involvement

Every action is assigned to a category and given a value. These category values form the features of the overall model.

Methodology — Threat-Based Value

The model is built on a custom expected threat grid assigning a threat value to every location on the pitch.

Goalkeeper Event Value = Threat Before Action − Threat After Action

Positive values reduce danger. Negative values increase opponent threat.

1. Shot-Stopping

Measured by threat change from shot to outcome. Clean saves score higher than rebounds. Conceded goals score negatively.

2. Distribution

Measured by xT change from pass start to end. Forward progressive passes are rewarded. Turnovers are penalised.

3. Leaving the Line

Sweeping and claiming crosses are valued based on threat neutralised.

4. Ball Handling

Secure catches are rewarded. Spills and rebounds are penalised.

Final Product

All event values are normalised per phase and combined into a composite score.

S = B + ωssV̄ss + ωdistV̄dist + ωllV̄ll + ωbhV̄bh

This produces a 0–100 Match Score.

The model produces:

  • Half-pitch heatmaps
  • Event point maps
  • Worst 10 distribution plot
  • Detailed scorecard and Excel report

Final Thoughts

This model is a strong starting point for comparing goalkeeper performance across games. It provides actionable insight for coaching and performance analysis.

The next step is refining the model and packaging it into a Python tool so others can use it with their own event data.
