Creating an Actionable Goalkeeper Value Model (GVM)

I am a very chaotic person by nature, and I need structure to make sure everything works right. When the structure isn’t good enough, projects stay on the shelf for a long time. One of those projects was the Goalkeeper Value Model. Not anymore.

Goalkeeping data is not as available in mainstream data sources. More importantly, goalkeeping is harder to measure with on-ball data because much of the role is technical, positional, and preventative rather than reactive. Media focuses on how goals are scored, not how they are prevented. This model is my contribution to changing that.

Introduction

Goalkeepers are often evaluated only through shot-stopping metrics linked to attacking data. But goalkeeping includes distribution, leaving the line, reflexes, ball handling, sweeping, and set piece control. With the right distinctions, we can build meaningful goalkeeper metrics.

Data Collection, Manipulation and Explainer

The data used is Opta/StatsPerform event data from the 2024–2025 Serie A season, collected on August 18th, 2025.

Working with Opta data requires extracting endX and endY from qualifiers. Events and qualifiers are essential for correctly mapping goalkeeper actions. Only goalkeepers with a minimum of 900 minutes are included for analysis stability.

Aim

The aim is to show how on-ball event data can be used to distinguish goalkeeper performance categories and create a model that gives a clear overview of performance per match or season.

Theory — Five Performance Scores

  • Shot-stopping
  • Leaving the line
  • Distribution
  • Ball handling
  • Set piece involvement

Each action is assigned to one of these categories and given a value. These scores form the features of the final model.

Methodology — Threat-Based Value Model

A custom expected threat grid assigns value to every pitch location. Each goalkeeper action changes this value.

Event Value = Threat Before Action − Threat After Action

Shot-Stopping

Clean saves score higher than rebounds. Goals conceded are heavily penalised.

Distribution

Forward progressive passes increase value. Turnovers decrease value.

Leaving the Line

Sweeping and cross claims are valued by the danger they remove.

Ball Handling

Secure control is rewarded. Spills and rebounds are penalised.

Final Product

Event values are normalised per phase and combined into a composite match score.

S = B + ωssV̄ss + ωdistV̄dist + ωllV̄ll + ωbhV̄bh

This produces a 0–100 match score and several key visualisations:

  • Half-pitch heatmaps
  • Event point maps
  • Worst 10 distribution plot
  • Detailed scorecard and Excel report
