Goalkeeper Value Model (GVM)

Most goalkeeper metrics focus almost exclusively on shot-stopping. Saves, save percentage, post-shot xG minus goals conceded — all valuable, but incomplete. A goalkeeper’s influence on a match starts long before a shot is taken and continues long after.

The Goalkeeper Value Model is designed to measure the total impact a goalkeeper has on preventing and creating threat using only event data. It evaluates how a goalkeeper changes the probability landscape of a possession through distribution, positioning, sweeping actions, handling, and shot-stopping.

1. Data

The model uses raw Opta/StatsPerform event data with XY coordinates and qualifiers. Only goalkeepers with sufficient minutes are evaluated to ensure stability in the metrics.

2. Core Idea

Every goalkeeper action changes the likelihood that a team will concede or create danger. Using an expected threat grid, we measure how much each action increases or decreases this threat.

Goalkeeper Value = Threat Before Action − Threat After Action

Positive values indicate actions that reduce danger. Negative values indicate actions that increase opponent threat.

3. Performance Phases

The model separates goalkeeper performance into five measurable phases:

  • Shot-stopping — value gained from preventing goals and controlling rebounds.
  • Distribution — value from moving the ball into more threatening areas for the team.
  • Leaving the line — sweeping actions and proactive interventions.
  • Ball handling — secure claims versus spills that create danger.
  • Set piece involvement — influence during defensive set-piece situations.

4. Methodology

For each goalkeeper event, we map the start and end location onto an expected threat grid. The difference between the two becomes the event value.

These values are aggregated per phase and normalized by event counts to avoid volume bias.

5. Aggregation

Phase scores are combined into a composite score that reflects overall goalkeeper impact. This can be applied on a match, season, or career level.

GVM Score = Weighted Sum of Phase Values → Normalized to 0–100 scale

6. What This Reveals

This model highlights goalkeeper qualities that traditional metrics miss:

  • Which goalkeepers actively improve team build-up
  • Which goalkeepers prevent danger before shots occur
  • Which goalkeepers create problems with poor handling or distribution
  • How different goalkeepers profile stylistically

7. Applications

The model can be visualised through heatmaps, event maps, and phase scorecards to identify strengths, weaknesses, and tactical fit.

Final Thoughts

Goalkeeping is not a single-skill role. By quantifying how goalkeepers influence threat throughout possessions, the Goalkeeper Value Model provides a more complete evaluation of performance using only event data.
