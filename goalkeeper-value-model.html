Creating an Actionable Goalkeeper Value Model

Goalkeepers are underrepresented in data studies. Much of football analytics focuses on how goals are scored rather than how goals are prevented. This model aims to change that by quantifying goalkeeper impact using on-ball event data.

Introduction

Goalkeeping is more than shot-stopping. Distribution, sweeping, leaving the line, and ball handling all influence match outcomes. By separating these categories, we can build meaningful metrics and create a model that evaluates goalkeeper performance in a structured, actionable way.

Data Collection

The model uses Opta/StatsPerform event data from the 2024–2025 Serie A season. Only goalkeepers with a minimum of 900 minutes played are included. Event qualifiers such as endX and endY are extracted to allow spatial analysis of passes and actions.

Aim

The aim is to show how event data can be used to distinguish goalkeeper profiles and evaluate performance across matches and seasons through a single, interpretable model score.

Theoretical Framework

The model evaluates five core performance categories:

  • Shot Stopping
  • Leaving the Line
  • Distribution
  • Ball Handling
  • Set Piece Actions

Every goalkeeper action is assigned a value and mapped to one of these categories, allowing aggregation into both category scores and a total performance score.

Methodology — Threat-Based Value

A custom expected value grid assigns a threat value to every pitch location. Each goalkeeper action is evaluated based on how it changes opponent threat between the start and end of the event.

  • Shot Stopping: Value based on threat removed by saves or threat created by rebounds/goals conceded.
  • Distribution: xT change from start to end of passes, rewarding progression and penalising turnovers.
  • Leaving the Line: Threat removed by sweeps, clearances, and cross claims.
  • Ball Handling: Rewarding secure catches and penalising spills or rebounds.

Final Model Score

S = B + ωss·Vss + ωdist·Vdist + ωll·Vll + ωbh·Vbh

This produces a Match Score on a 0–100 scale, combining all phase contributions into a single interpretable value.

Model Outputs

  • Half-pitch heatmap of value creation
  • Event points map by category and value
  • Worst 10 distribution actions plot
  • Scorecard with phase scores and traditional stats
  • Score timeflow across the match
  • Phase impact and WAR%

Analysis Example

The worst distribution plot reveals structural passing issues that goalkeeper coaches can address. The scorecard shows total score, distribution profile, crosses claimed, and phase impact, providing both tactical and technical insight.

Final Thoughts

This model is an initial step toward structured goalkeeper analysis. It highlights where performance improves or declines and offers actionable insights for coaches and analysts. Future work will refine the model and be released as a Python package for broader use with event data.
