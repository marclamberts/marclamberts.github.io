Notes & models

Research

Write-ups on the models I've built to quantify shot danger, goalkeeping value and set-piece threat, using event data from men's and women's football.

  • Expected Shot Danger

    A two-stage probability model measuring how dangerous a shot is before and after it reaches the target, incorporating blocked shots and contextual shot features beyond traditional xG.

  • Entropy-Adjusted Expected Goals

    An extension of expected goals that values uncertainty and defensive disruption, rewarding shots that create higher entropy for the defending team.

  • Goalkeeper Value Model

    A threat-based framework quantifying goalkeeper impact across shot-stopping, distribution, sweeping, and ball handling using event data.

  • Set Piece Model

    A model evaluating the structure, delivery, and second-phase danger of set pieces, measuring how teams create and concede threat from dead-ball situations.
